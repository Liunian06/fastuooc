# Fast UOOC

Fast UOOC是一款面向UOOC在线学习页面的Tampermonkey用户脚本，用于减少重复的播放器操作，让课程可以按照目录顺序自动播放。

> 本项目只在当前浏览器页面中辅助播放器和测验复习，不提供课程内容，也不绕过平台账号、权限或课程访问控制。AI参考功能不会代替用户勾选或提交测验。

## 功能

- 自动将视频播放速度设置为2倍速。
- 自动静音，并在播放器重建或线路切换后重新应用静音状态。
- 自动播放当前可用的视频资源。
- 当前线路加载失败时，从页面或Video.js播放器中寻找其他可用视频资源并尝试切换。
- 当前视频播放完成后自动进入下一个视频，不需要人工确认。
- 同章节内的视频播放完成后，自动进入下一章节的第一个可用视频。
- 支持连续遍历多个章节，直到找不到下一个可播放视频。
- 兼容旧版Angular目录结构和新版页面中常见的HTML5 Video/Video.js播放器。
- 在支持的平台页面中拦截失焦暂停策略，并在浏览器切到后台后进行播放恢复检查。
- 右下角提供简洁的Fast UOOC悬浮控制面板。
- 支持浅色、深色和跟随系统三种主题模式。
- 播放器、主题和AI接口配置会在刷新页面后保留；API Key优先保存在Tampermonkey专用存储中。
- 提供GitHub项目入口，方便查看源码和提交问题。
- 支持配置OpenAI兼容Chat Completions接口，为测验选择题生成仅供参考的AI选项。
- 每道选择题先进行3次独立判断，必要时追加2次；所有请求全局最多10路并发。
- AI结果仅展示在题目旁，不自动勾选、不自动提交测验。

## 安装

1. 安装[Tampermonkey](https://www.tampermonkey.net/)或兼容的用户脚本管理器。
2. 打开本仓库中的`uooc-auto-player.user.js`。
3. 在用户脚本管理器中创建新脚本，将文件内容完整复制进去并保存。
4. 打开或刷新UOOC课程学习页面。

也可以直接使用下面的链接一键安装：

[一键安装到Tampermonkey](https://raw.githubusercontent.com/Liunian06/fastuooc/main/uooc-auto-player.user.js)

脚本匹配的主要页面地址包括：

- `www.uooc.net.cn/home/learn/*`
- `*.uooc.net.cn/home/learn/*`
- `*.uooconline.com/home/learn/*`
- `*.uooc.online/home/learn/*`
- `www.uooc.net.cn/exam/*`
- `*.uooc.net.cn/exam/*`
- `*.uooconline.com/exam/*`
- `*.uooc.online/exam/*`

课程页中的测验通常通过同源`iframe`加载，脚本会同时检查课程主页面和可读取的同源考试页面。跨域`iframe`由于浏览器同源策略无法读取时会自动跳过。

## 使用方式

脚本加载后，悬浮窗会出现在页面右下角。面板中的状态和开关均为中文显示。

### 自动控制

“自动控制”是总控开关：

| 自动控制 | 自动连播、静音、后台播放 |
| --- | --- |
| 开启 | 三项强制开启，并置灰为不可单独修改状态 |
| 关闭 | 三项恢复可操作，可以分别开启或关闭 |

关闭总控时，三个子开关会保留各自已经保存的状态，不会被自动清空。

### 其他控件

- **自动连播**：控制视频结束后是否寻找并播放下一个视频。
- **静音**：控制播放器是否保持静音。
- **后台播放**：控制是否尝试阻止平台的失焦暂停并恢复后台播放。
- **界面主题**：依次切换“跟随系统”“浅色”“深色”。
- **GitHub图标**：在新标签页打开项目主页。
- **Chevron按钮**：折叠或展开控制面板。

## 测验题目导出

在课程测验页面或直接打开考试页面后，点击悬浮窗中的“导出题目”按钮，脚本会读取当前页面中已经渲染的题目和选项，并自动下载一个Markdown文件。

导出内容包括：

- 试卷标题、导出时间、题目数量和来源页面。
- 每道题独立的题号和题型。
- 题干文本。
- 每个选项的字母和文本。
- 页面中显示的分值（如果存在）。
- 题干或选项中的图片会以`[图片: ...]`占位文本保留。

每道题会被单独格式化为一个Markdown二级标题，例如：

```markdown
## 1. 一、单选题

**题目：** 题目内容

- **A.** 选项内容
- **B.** 选项内容
- **C.** 选项内容
- **D.** 选项内容
```

脚本只导出页面上可见或已渲染的题目与选项，不读取、推断或导出正确答案，也不会自动提交测验。若当前页面尚未完成加载，先等待题目显示后再点击导出。

## AI参考选项

点击悬浮窗中的“AI设置”，填写OpenAI兼容Chat Completions接口信息：

- **接口地址**：可以填写完整的`/chat/completions`地址，也可以填写服务的`/v1`地址，脚本会自动补全路径。
- **API Key**：用于请求鉴权，优先保存在Tampermonkey专用存储中，不写入普通页面`localStorage`。
- **模型名称**：例如`gpt-4o-mini`或第三方服务提供的兼容模型名称。
- **超时时间**：单次请求的超时上限，范围为5000到120000毫秒。

### 提示词与题型判断

脚本不发送`system`消息，完整指令、题型、题干和选项全部放在一条`user`消息中。提示词会要求模型：

- 数学、物理、化学、生物等推理或计算题直接分析过程并判断选项。
- 历史、地理、政治、经济、法律、学校信息、机构信息、时事等事实性题目，如果当前接口实际提供联网搜索或浏览工具，先使用工具核验关键事实。
- 接口没有可用搜索工具时，不得伪装已经搜索；无法可靠判断时输出“无法确定”，脚本会将其视为无效回答。
- 单选题只输出一个选项标签，例如`A`。
- 多选题输出完整选项组合，按题目顺序用英文逗号分隔，例如`A,C`。

脚本会从页面题型文本、选项控件等信息识别单选题和多选题。多选题按完整选项组合进行投票，不会把不同回答中的选项直接拼接，避免生成不存在的答案组合。

### 请求与重复分析

点击“AI参考”后，脚本会对当前页面每道有选项的题目独立发起3次请求。只有当3次结果不完全一致时，才会再发起2次请求；最终在最多5次有效回答中选择唯一票数最高的答案组合。若最高票数并列，页面显示“无法确定”，不展示具体选项。

如果当前页面已经生成过AI参考结果，再次点击“AI参考”会弹窗询问：

- **覆盖全部**：重新分析当前页面所有选择题。
- **仅重试无法确定**：只重新处理已有结果为“无法确定”的题目，已经确定的题目跳过。

所有AI请求共用一个全局队列，同时最多10个并发请求；尚未从队列取出执行的题目显示“等待分析中…”，真正开始请求后才显示“分析中…”。单次请求`max_tokens`为50。接口请求格式为OpenAI Chat Completions格式，脚本只读取`choices[0].message.content`，并按当前题目的选项标签解析。

AI结果仅显示为题目旁的参考标记，例如单选题`AI参考：B（5/5）`或多选题`AI参考：A、C（4/5）`。脚本不会自动勾选任何选项，不会修改选项的`checked`状态，也不会提交测验；请根据题目、课程材料和AI参考自行判断。API Key会发送到你在设置中填写的第三方接口，请确认该服务的隐私和使用条款。

## 自动连播顺序

自动连播会按照课程目录顺序处理资源：

1. 读取当前课程目录中的章节、节和小节资源。
2. 筛选类型为视频的资源。
3. 在当前视频之后寻找下一个可用视频。
4. 如果当前章节没有下一个视频，则点击下一章节并等待目录资源加载。
5. 播放下一章节中的第一个可用视频。
6. 如果章节中没有视频，继续尝试后续章节。
7. 到达课程末尾或没有可用资源时停止，并在页面上给出提示。

脚本优先模拟页面目录中的原生资源点击，让旧版和新版UI自行执行平台原有的切换流程；找不到目录节点时，再尝试使用Angular状态服务进行路由跳转。

## 实现说明

脚本不依赖构建工具或第三方npm包。播放器功能在页面内运行；AI参考使用`GM_xmlhttpRequest`调用用户配置的第三方OpenAI兼容接口，并使用`GM_getValue`、`GM_setValue`保存API Key。

当前实现会按页面实际运行环境尝试使用以下能力：

- 原生HTML5`video`元素。
- Video.js实例及其候选资源列表。
- Angular页面的Injector、Scope和目录数据。
- 课程服务的`getUnitLearn`接口，用于按需补充章节资源。
- 旧版页面的`goSource(source, 'section')`和`goSource(source, 'subsection')`目录点击流程。
- 页面状态服务的资源路由跳转作为备用方案。

## 后台播放说明

后台播放受到浏览器、操作系统、平台脚本和节能策略共同影响。Fast UOOC会尝试：

- 关闭已识别的UOOC失焦暂停处理。
- 监听`visibilitychange`、`blur`、`focus`和`pageshow`等生命周期事件。
- 定期检查视频是否被暂停，并在条件满足时恢复播放。
- 在恢复播放时重新应用倍速和静音设置。

这不能保证在所有浏览器、系统节能模式、网络环境或平台版本中始终保持后台播放。浏览器首次自动播放也可能要求用户先手动点击一次播放按钮。

## 已知边界

- UOOC前端升级后，如果目录结构、Angular服务名称、播放器实现或接口返回格式发生变化，自动连播可能需要适配。
- 资源是否可播放由平台返回的数据和浏览器实际加载结果决定。
- 线路切换只处理脚本能够从页面、播放器实例或目录接口中读取到的候选资源。
- 脚本不会替代平台原有的学习进度、完成状态或课程考核逻辑。
- 当前验证包括脚本语法检查和本地测验HTML结构核对；不同课程、账号和前端版本仍需要在真实页面中分别测试。

## 开发与检查

在项目目录中执行语法检查：

```powershell
node --check .\\uooc-auto-player.user.js
```

建议提交前检查：

- Tampermonkey能否正常保存并加载脚本。
- 新旧UI下是否都能找到播放器和目录资源。
- 视频结束后是否能进入同章节下一个视频。
- 章节末尾是否能进入下一章节。
- 线路失败时是否能尝试其他资源。
- 自动控制开启和关闭时，三个子开关是否符合总控规则。
- 浏览器切到后台后，播放器是否仍能按预期运行。
- 测验页面点击“导出题目”后，导出的Markdown是否包含每道题和完整选项。
- AI设置中的接口测试是否成功，AI参考结果是否只显示在题目旁且不改变选项状态。
